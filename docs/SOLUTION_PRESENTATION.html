05 / DATA QUALITY

Keep uncertainty visible.

Controls built into the workflow

  • Two independent qualified frames before plate confirmation.
  • Separate trackers and sessions per camera.
  • No person-to-vehicle class remapping.
  • No silent local-video substitution for failed RTSP.
  • Source type and timestamp basis retained.
  • Uncertain reads do not raise confirmed-match alerts.
  • Transaction-safe sightings and alerts.
  • Unique evidence names and controlled file access.

Source camera resolution limits recognition. Scores are not calibrated identity probabilities.

07 / SCALE & SECURITY

Process regionally.
Investigate centrally.

Deployment path toward the statewide requirement

Scale design

  • Regional ingestion and GPU workers.
  • Durable event transport; PostgreSQL/PostGIS.
  • Selected evidence in object storage.
  • Measured capacity, backpressure and failover.

Security design

  • Current: local restriction, sessions, roles and audit.
  • Deployment: OIDC and department-scoped access.
  • HTTPS, managed secrets and encrypted storage.
  • Retention, backup and recovery exercises.

Illustrative: 80,000 × 2 Mb/s = 160 Gb/s if all video is centralized. Actual sizing and costs require measurements and quotes.
